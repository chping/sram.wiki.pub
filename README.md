# SRAM 工程知识库

本项目整理静态随机存取存储器（Static Random-Access Memory，SRAM）的工程文档，涵盖器件、位单元、子阵列、外围电路及宏级指标。

各文档保留定义、适用条件、仿真与测试方法、评价判据及文献定位。
